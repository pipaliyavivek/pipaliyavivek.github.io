About this game

Font Style has a feature called text effect that includes wavy text, adjustable text size, text outline width, and other options. By using the wavy text feature, your text can be displayed in a fun and dynamic manner. It also offers you an option to set a text in italics. By using Font Style, you can enter your own text and customize it with a unique font style. It also offers you the option to modify the character effect as it provides features such as character spacing and text width. Font Style is a stylish font maker app which allows you to create fancy text. With Font Style, you can create your own images by entering your own text. It allows you to add background colors to your images. Font Style for Story is an application that is easy to use and allows you to customize the size and placement of your text. Once you've created images by adding your own text, tap the save button to save the images to your camera roll. To make your story more creative, simply select them from a camera roll and add them to your story.
