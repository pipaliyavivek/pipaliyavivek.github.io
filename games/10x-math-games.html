About this game

10x is a number logic board game. It's simple. Drag number blocks on the board to get total of 10 in any row or column and then you get scores! Features Number Puzzle： ● Easy to play, challenging to master – Number matching game ● Use magic hat when need help! ● Simple and cool interface ● Classic merge games and block games ● NO WIFI? NO PROBLEM – Enjoy block puzzle games anytime, anywhere! ● Easy to learn and play, and pleasurable game for all ages! 10x: Number Puzzle Game is a true brain puzzle game, if you ever love make hexa number, wood block puzzle, merge number puzzle, 2048 or similar ones, you will love get this number game. Enjoy a TENX puzzle game and challenge your brain! Tenx : Math Puzzle is an addictive relaxing number game.
